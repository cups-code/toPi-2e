# Tangents and Normals
## Tangents
A tangent is the linear function at a given point on the curve. It is used to find the instantaneous rate of change of a curve at a certain point.

To find the gradient of the tangent, substitute the given x-value into the derivative.
## Normals
A normal is the linear function perpendicular to the tangent at any given point on the curve.

To find the equation of a normal, use the perpendicular gradient formula ($m_T times m_N=-1$) to find $m_N$.

> [!Example] Example: $f(x)=x^2$
> To find the equation to the normal:
> (1) Find the tangent gradient.
> $$"Let" space f(x)=x^2, space "thus" space f'(x)=2x \
> "Let tangent be at" space x=2, y=4 \
> f'(2)=2(2)=4 \
> m_T=f'(x) \
> m_T=f'(2)=4 \
> m_T=4
> $$
> 
> (2) Find the normal function.
> $$
> m_T times m_N = -1 \
> 4 times m_N = -1 \
> m_N = -1/4 \
> y_N = -1/4x+c \
> "Sub" (2,4) \
> 4=-1/4 times 2 + c \
> 4=-1/2 + c \
> 4.5=c \
> y_N=-1/4 x + 4.5 \
> $$

> [!Tip] 
> You’ll learn how to get $f'(x)=2x$ in [[3. Differentiation from First Principles]].
