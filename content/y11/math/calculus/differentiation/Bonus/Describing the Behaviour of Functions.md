# Describing the Behaviour of Functions
f(x) is…
1. increasing at … if f’(x) > 0
2. decreasing at … if f’(x) < 0
3. stationary at … if f’(x) = 0

> [!Example]
> ${} f(x)=x^3+4x^2-3$
> $$
> f(x)=x^3+4x^2-3 \
> f'(x)=3x^2+8x \
> (f'(x)=0) \
> 3x^2+8x=0 \
> x(3x+8)=0 \
> therefore x=0 "or" -8/3
> $$
> ---
> $$
> f'(x)>0 \
> therefore x< -8/3 "or" x > 0
> $$
> ---
> $$
> f'(x)<0 \
> therefore -8/3 < x < 0
> $$
