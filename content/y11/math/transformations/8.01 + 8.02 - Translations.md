# Translations
Translation is the process of moving a function.
## Vertical Translations

$$y=f(x)+d$$
$$y->y+d$$
Take the function $f(x)=x^2$.
```typst
#import "@preview/simple-plot:0.8.0": plot

#set page(width: auto, height: auto, margin: 0.5cm)

// Showcases: major grid only, grid-label-break, axis extension, integer ticks
#plot(
  xmin: -3, xmax: 3,
  ymin: -1, ymax: 9,
  xlabel: $x$,
  ylabel: $y$,
  show-grid: "major",
  (fn: x => calc.pow(x, 2), stroke: blue + 1.5pt, label: $x^2$, label-pos: 0.7, label-side: "below-right"),
)
```
When $f(x)=x^2$ is transformed to $f(x)=x^2+1$ ($y=f(x)+1$), the graph is shifted up by 1 unit.
```typst

// Showcases: major grid only, grid-label-break, axis extension, integer ticks
#plot(
  xmin: -3, xmax: 3,
  ymin: -1, ymax: 9,
  xlabel: $x$,
  ylabel: $y$,
  show-grid: "major",
  (fn: x => calc.pow(x, 2) + 1, stroke: blue + 1.5pt, label: $x^2$, label-pos: 0.7, label-side: "below-right"),
)
```

## Comparison
$$y=f(x-c)+d$$

| Vertical Translation                              | Horizontal Translation                            |
| ------------------------------------------------- | ------------------------------------------------- |
| $d: "Vertical Translation"$                       | $c:"Horizontal Translation"$                      |
| $d>0 = "Shift Up"$<br><br>$"e.g." d=3, f(x)+3$    | $c>0 = "Shift Right"$<br><br>$"e.g." c=3, f(x-3)$ |
| $d<0 = "Shift Down"$<br><br>$"e.g." d=-3, f(x)-3$ | $c<0 = "Shift Left"$<br><br>$"e.g." c=3, f(x+3)$  |
> [!Example]
> Take the function $f(x)=x^2$. Shift it up by three and shift it left by four.

```typst
#import "@preview/simple-plot:0.8.0": plot

#set page(width: auto, height: auto, margin: 0.5cm)

#plot(

  ymin: -2, ymax: 10,
  xlabel: $x$,
  ylabel: $y$,
  show-grid: "major",
  (fn: x => calc.pow(x+4, 2) + 3, stroke: blue + 1.5pt, label: $(x+4)^2+3$, label-pos: 0.5, label-side: "below"),
)
```
