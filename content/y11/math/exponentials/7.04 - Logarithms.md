# Logarithms


| $B^P=A$     | $log_B A=P$       |
| ----------- | ----------------- |
| $2^3=8$     | $log_2 8 = 3$     |
| $2^10=1024$ | $log_2 100 = 2$   |
| $2^10=1024$ | $log_2 1024 = 10$ |

$$
ln=log_e "(natural log)"
$$
## Logarithm Properties
$$
log_a a=1 \
log_a 1 = 0 \
log_a a^x = x \
a^(log_a x)=x 
$$

> [!Tip]
> You can view $log_a a^x = x$ as $log_a$ and $a$ cancelling each other.

## Exponential Functions

> [!Tip] Related
> See [[7.01 + 7.02 - Exponential Functions and Euler's Number]].

$$
"Let" y=a^x, "thus" x=log_a y
$$
The same properties from exponential functions (e.g. $a>0$) also apply to logarithms. $a$ can also not equal to 1. See [[7.01 + 7.02 - Exponential Functions and Euler's Number]] for every property.
