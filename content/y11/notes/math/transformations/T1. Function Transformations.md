# Function Transformations
Welcome to function (or graph) transformations. You’ll be able to learn how to shift, dilate, and reflect a function algebraically. Here, you’ll find:
- [[#Translations]] → how to move a function horizontally and/or vertically
- [[#Dilations]] → how to stretch or compress a function towards the x and/or y axis
- [[#Reflections]] → how to reflect a graph across the x and/or y axis
- [[#Combined Transformations]] → how to use translations, dilations, and reflections simultaneously

---
# Translations
Translation is the process of moving a function.
## Vertical Translations

$$
y=f(x)+d \ y->y+d
$$

Take the function $f(x)=x^2$.

When it is transformed to $f(x)=x^2+1$ ($y=f(x)+1$), the curve is shifted up by 1 unit.
## Horizontal Translations

$$
y=f(x-c) \
x->x+c
$$

Take the function $f(x)=x^3$. When it is transformed to $f(x)=x^3-1$ ($y=f(x)-1$), the curve is shifted down by 1 unit.
## Comparison
> [!Tip]
> $d$ is for vertical translation, $c$ is for horizontal translation.

$$
y=f(x-c)+d
$$

| Vertical Translation                              | Horizontal Translation                            |
| ------------------------------------------------- | ------------------------------------------------- |
| $d: "Vertical Translation"$                       | $c:"Horizontal Translation"$                      |
| $d>0 = "Shift Up"$<br><br>$"e.g." d=3, f(x)+3$    | $c>0 = "Shift Right"$<br><br>$"e.g." c=3, f(x-3)$ |
| $d<0 = "Shift Down"$<br><br>$"e.g." d=-3, f(x)-3$ | $c<0 = "Shift Left"$<br><br>$"e.g." c=3, f(x+3)$  |

> [!Example]
> Take the function $f(x)=x^2$. Shift it up by three and shift it left by four.

# Dilations
> [!Abstract] Definition
> Dilation is the compression or stretching of a function.
## Vertical Dilation
$$
y=k f(x) \
y->y/k "or" y->y/b
$$
When vertical dilation is applied, the graph either moves towards (compresses or is shrunk) or moves away (stretches) from the x-axis.

These conditions apply for vertical dilation.
- $0<k<1$ :: It is compressed or shrunk towards the x-axis.
- $k>1$ :: It is stretched away from the x-axis.

> [!Example] Application
> With graphing technology (e.g. [Desmos](https://desmos.com/calculator)), input the following functions:
> $$
> f(x)=x \
> y=3f(x) \
> y=1/4f(x)
> $$
> Notice how with $y=3f(x)$ that the function stretches away from the x-axis. Notice how the opposite effect occurs with $y=1/4 f(x)$.

## Horizontal Dilation
$$
y=f(k x) \
"(In terms of scale factor)" y=f(1 /k x) \
x->1/k times x
$$
When horizontal dilation is applied, the graph either moves towards (compresses or is shrunk) or moves away (stretches) from the y-axis.

These conditions apply for horizontal dilation.

> [!Example] Application
> With graphing technology (e.g. [Desmos](https://desmos.com/calculator)), input the following functions:
> $$
> f(x)=x \
> y=f(2x) \
> y=f(1/6 x)
> $$
> Notice how with ${} y=f(1/6 x) {}$ that the function stretches away from the x-axis. Notice how the opposite effect occurs with $y=f(2 x)$. (Remember that it is the reciprocal of $k$ that is being used as the scale factor, so the scale factor of $y=f(1/6x)$ is 6, and the scale factor of $y=f(2 x)$ is $1/2$.)


> [!Tip]
> To dilate a function horizontally, you must multiply x by the reciprocal of k. This is because the scale factor is actually $1/k$.
> $$
> k y=x \
> y=x/k \
> y=1/k times x \
> therefore y = 1/k x
> $$
## Comparison
$$
y=b f(a x) "or" y=b f(1/a x)
$$
> [!Tip]
> $a$ is for horizontal dilation, $b$ is for vertical dilation.

| Vertical Dilation                              | Horizontal Dilation                            |
| ---------------------------------------------- | ---------------------------------------------- |
| $b: "Vertical Dilation"$                       | $a:"Horizontal Dilation"$                      |
| $0<b<1 -> "Compress or Shrink towards x-axis"$ | $0<a<1 -> "Compress or Shrink towards y-axis"$ |
| $b>1 -> "Stretch towards x-axis"$              | $a>1 -> "Stretch towards y-axis"$              |

# Reflections
> [!Abstract] Definition
> Reflections are a type of transformation, allowing for the graph to be flipped across a line to create a mirror image on the other side. 

Reflections are similar to [[8.04 + 8.05 - Dilations|dilations]], since it is, with respect to the function $y=k f(x)$, $k=-1$.

> [!Note]
> In Mathematics Advanced, only reflections about the x and y-axis will be explored.
## Vertical Reflections
$$
y=-f(x) \
y->-y
$$
Vertical reflections are reflections about the x-axis. This is when every y-value is flipped.

Let $y=x^3$.

| x   | 0   | 1   | 2   |
| --- | --- | --- | --- |
| y   | 0   | 1   | 8   |

Now, reflect $y=x^3$ vertically. This should now return as $y=-(x^3)=-x^3$.

| x   | -2  | -1  | 0   | 1   | 2   |
| --- | --- | --- | --- | --- | --- |
| y   | 8   | 1   | 0   | -1  | -8  |


> [!Tip]
> In vertical reflections, the y-intercept of the function CAN change. For instance, let $f(x)=x^3+1$. The y-intercept of this function is (0, 1). If it was vertically reflected ($-f(x)$)…
> $$
> f(x)=x^3+1 \
> -f(x)=-(x^3+1) \
> = -x^3-1
> $$
> The y-intercept is now (0, -1).

## Horizontal Reflections
$$
y=f(-x)\
x->-x
$$
Horizontal reflections are reflections about the y-axis. This is when every x-value is flipped.

Let $y=x^3$.

| x   | 0   | 1   | 2   |
| --- | --- | --- | --- |
| y   | 0   | 1   | 8   |

Now, reflect $y=x^3$ horizontally. This should now return as $y=(-x)^3$. Thus, its values are the same (since it is an even function).

| x   | -2  | -1  | 0   | 1   | 2   |
| --- | --- | --- | --- | --- | --- |
| y   | 8   | 1   | 0   | -1  | -8  |
> [!Tip]
> Horizontal reflections CANNOT change the y-intercept because the y-values do not change (only the x-values do).
## Combined Reflections
To combine reflections, see below.
$$
y=-f(-x)
$$
# Combined Transformations
> [!Abstract] Note
> Refer to the previous sections for the purpose of these pronumerals.

$$
y=b[1/a (x-c)]+d
$$
> [!Warning] Warning
> This formula is not included in the new syllabus. However, it may still be useful in certain situations, such as determining the order of transformations or having a formula to utilise transformations.

Additionally, if you don’t want to utilise this formula, you should remember this order of transformations.

$$
"Horizontal Dilation" -> "Vertical Dilation" -> "Horizontal Translation" -> \
"Vertical Translation"
$$

Reflections can be during the dilation phase of transformations.
